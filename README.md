# Meyers Home & Hardware — Hardware Store Website

## Overview

A responsive website of a local hardware store using HTML and CSS. 

## Live Website

[Link to the GitHub Pages/deployed website.](https://ghs-tech.github.io/hardware_store_site/)

## Features

- Responsive navigation
- Product categories
- Brand showcase
- Services section
- Meet the team section
- Store information
- Embedded Google Maps
- Call-to-action buttons
- Footer navigation

## Technologies Used

- HTML5
- CSS3
- Flexbox
- CSS Media Queries
- Git
- GitHub
- GitHub Pages

## Design & Branding

- Primary: Dark Navy (#253342), chosen for it's dark professional foundation and excellent contrast with the light background
- Accent: Safety Orange (#F4511E), chosen for being associated with construction and safety equipment.
- Background: Light Gray (#F4F5F7), chosen for being easier on the eyes then a white background, and making the other colors stand out.
- Fonts: *Inter*, Arial, sans-serif

## Responsive Design

The website uses CSS Flexbox and media queries to adapt the layout across different screen sizes. Navigation, images, product categories, buttons, and content sections are adjusted for smaller screens. Horizontal scrolling is also used for the product categories where appropriate.

## Development Process

The website was developed progressively, starting with the HTML structure and content before moving on to CSS styling and layout. Flexbox was used to organize the main sections, while media queries were added to make the website responsive across different screen sizes. The design was then tested and refined to improve spacing, alignment, and usability before being managed and deployed using Git and GitHub.

## Challenges & Solutions

- Challenge: Maintaining the layout on smaller screens.\
Solution: Used CSS media queries and flexible layouts to adapt the navigation, categories, team section, and footer. Still a work in progress.

- Challenge: Applying the tint on the background.\
Solution: Used linear-gradient for the color, and changed the URL to the style sheet.
